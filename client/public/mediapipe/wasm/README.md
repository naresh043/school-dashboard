# MediaPipe Tasks Vision runtime files

The adjacent `.js` and `.wasm` files are copied from `@mediapipe/tasks-vision` version 1.2.0 so the runtime can load locally in production. SIMD and non-SIMD variants are included; the MediaPipe fileset resolver selects the compatible variant.
